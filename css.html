Каскадні таблиці стилів: CSS

Частково про CSS зазначалось у попередньому модулі.

Рекомендований спосіб додавати стилі для всього сайту - це окремий файл, що підключається за допомогою тегу link. Суть файлу - це послідовне застосування стилів для груп елемнтів, які потрапляють до селекторів. Можна сказати, що кожна команда CSS-файлу має структуру: 

        Знати все що відповідає такому-то селектору {
            і застосувати 
            до нього даний 
            набір стилів}

Термін "каскадний" стверджує те, що кожна наступна команда буде поєднуватись з попереднім.

Основні селектори

Селектор Значення
* Всі елементи
img Всі елементи з тегом <img>
middle Елементи з класом "middle"
.selector-table th Всі елементи <th> всередині таблиці з класом "selector-table". Пробіл означає "всередині", пробілом можуть розділятись і інші види селекторів. Наприклад, "p b" всі теги <b> всередині тегів <p>. ".bold .small" - всі елементи з класом "small" всередині елементів з класом "bold".
p, b Кома позначає поєднання - спільні стилі для двох (або більше) селекторів.
