Елементи форм

<form> - головний контейнер, який об'єднує всі елементи форми та визначає, куди та яким методом надсилати дані (action, method).

Атрибути action та method у тезі <form> в HTML визначають, куди і як саме будуть відправлені дані з форми на сервер.

Атрибут Опис
action Визначає URL-адресу, на яку будуть відправлені дані форми
після її відправки. Якщо атрибут не вказаний, дані будуть відправлені
на ту ж саму сторінку, на якій знаходиться форма.
method Визначає HTTP-метод, який буде використаний для відправки даних
форми. Найпоширеніші значення: "GET" (дані додаються до URL) та "POST"
(дані надсилаються в тілі запиту).

<input> - універсальне поле для введення даних. Вигляд і поведінка залежать від атрибута type.

Тип Опис
text Звичайний однорядковий текст.
email, tel, number, date Спеціалізовані поля для пошти, телефону, чисел і дат.
password Поле для введення пароля (відображається як зірочки).
checkbox Прапорець для вибору одного або кількох варіантів.
radio Кнопка для вибору одного варіанту з групи.
submit, reset, button Кнопки відправки, скидання або звичайна кнопка.
file Поле для вибору файлу для завантаження.
<textarea> Багаторядкове текстове поле для введення великих обсягів тексту.
